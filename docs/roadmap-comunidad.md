# Roadmap de comunidad (Core)

## Objetivo
Consolidar una base open-core potente, usable y fácil de mejorar por la comunidad.

## Prioridades actuales
1. Estabilidad y bugs en flujos existentes.
2. UX de introducción de datos (menos fricción).
3. Calidad: tests y validaciones.
4. Documentación y onboarding de colaboradores.

## Módulos Core en evolución
1. Patrimonio
2. Presupuesto / cierre mensual
3. Guía / coach financiero v1
4. Familia / titularidad
5. Simulador financiero (progresivo)
6. Contabilidad (progresiva)
7. Cartera de inversión (posterior)

## Ideas de contribución (rápidas)
1. Mejorar estados vacíos / mensajes de error.
2. Tests de regresión para flows críticos.
3. Mejoras de accesibilidad y responsive.
4. Export/import y validación de datos.
5. DX: scripts y docs de desarrollo.

## Qué no es prioridad (ahora)
1. Billing/pagos
2. Admin SaaS
3. RBAC SaaS
4. Integraciones B2B
