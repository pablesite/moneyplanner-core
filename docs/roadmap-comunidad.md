# Roadmap de comunidad (Core)

## Objetivo
Consolidar una base open-core potente, usable y facil de mejorar por la comunidad.

## Prioridades actuales
1. Estabilidad y bugs en flujos existentes.
2. UX de introduccion de datos (menos friccion).
3. Calidad: tests y validaciones.
4. Refactor del backend por fases (mantenibilidad).
5. Documentacion y onboarding de colaboradores.

## Roadmaps activos
1. Backend refactor (profundo): `core/docs/roadmap-refactor-backend.md`

## Modulos en evolucion
1. Patrimonio
2. Presupuesto / cierre mensual
3. Guia / coach financiero v1
4. Familia / titularidad
5. Simulador financiero (progresivo)
6. Contabilidad (progresiva)
7. Cartera de inversion (posterior)

## Ideas de contribucion (rapidas)
1. Mejorar estados vacios / mensajes de error.
2. Tests de regresion para flows criticos.
3. Mejoras de accesibilidad y responsive.
4. Export/import y validacion de datos.
5. DX: scripts y docs de desarrollo.
6. Refactors pequenos del backend con tests previos.

## No prioritario ahora
1. Nuevos modulos grandes antes de estabilizar los existentes.
2. Cambios de packaging/comercializacion.
3. Integraciones externas complejas.
4. Refactors grandes sin impacto claro en usuario o calidad.
